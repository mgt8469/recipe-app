フルーツぎっしり

■ 混ぜるもの

卵2個
無脂肪ギリシャヨーグルト130g

作り方

  1. ふやかす（30分〜前夜）オートミールに豆乳を注いで冷蔵庫へ。デーツは熱湯大さじ2、ドライフルーツはぬるま湯に10分。冷凍フルーツは冷凍庫から出さない。
  2. クリームチーズを柔らかく70gを600Wで20〜30秒、マヨネーズくらいに。40gをボウルへ、30gは取り分け。冷たいまま混ぜるとダマが舌に当たります。
  3. 液体を混ぜるクリームチーズ40gに卵・ギリシャヨーグルト・レモンジャム・油を加えてなめらかに。ふやけたオートミール（豆乳ごと）、潰したデーツ、水気を切ったドライフルーツも加える。
  4. 粉を加える米粉（大さじ1を除く）・スキムミルク・BP・塩を合わせて加え、ゴムベラで粉が見えなくなるまで。米粉なので混ぜすぎても硬くならない。この時点でかなり固めが正解。
  5. 冷凍フルーツを、直前にここで初めて冷凍庫から出す。取り分けた米粉大さじ1をまぶし、半量だけ生地に5回だけ混ぜる。混ぜすぎると色が滲む。
  6. 型に入れて、残り半量を上に6等分し、残したフルーツを表面に押し込む。クリームチーズ30gも6つにちぎって乗せる。
  7. 焼く180℃予熱で28〜32分。竹串にしっとりした生地が少しつく状態で出す。型のまま10分置く。

パサつかせない、たったひとつのコツ。焼きすぎないこと。竹串が「完全にきれいに抜ける」まで焼いたら、それはもう焼きすぎ。余熱で中心まで火が通ります。

そして、翌日の方がおいしい。一晩置くと水分が全体に行き渡ってしっとりします。焼いた日に「思ったほどじゃないな」と感じても、翌朝もう一度食べて判断してください。

失敗しないための原則

ザラつきの原因は2つ。両方使わない。

  • おからパウダー … 自重の3〜4倍の水を吸う。翌日には口の中の水分まで持っていかれる
  • ホエイプロテイン … 加熱するとタンパク質が固まって水分を抱えられず、キシキシ・ゴムっぽくなる

→ 代わりにスキムミルク（脱脂粉乳）。タンパク質量は近いのに、焼き色と乳のコクが出て味はむしろ良くなる。

ミキサーの代わりは「浸水」。オートミールは30分以上浸せば粒感がほぼ消える。前夜からならなお良い。挽く工程が丸ごと不要になります。

油小さじ1をケチらない。1個あたりたった6kcal。しっとり感への貢献は絶大で、ここを抜くと別物になります。

フルーツを増やすときの原則。
かさは冷凍フルーツで稼ぎ、ドライフルーツは香り役に絞る。ドライは水分が抜けている分、同じ重さなら生の4〜5倍の糖質がある（レーズン30g と ブルーベリー30g で約4倍差）。

フルーツを増やしたら必ず生地側も調整する（この配合は調整済み）：豆乳を減らす／米粉を増やす／BPを増やす。ここを変えずにフルーツだけ足すと確実にべちゃっとします。

冷凍フルーツの選び方

冷凍と、お弁当への持っていき方

焼いて冷凍する

  1. 完全に冷ます。網の上で最低1時間。少しでも温かいうちにラップすると湯気が水滴になり、解凍時にべちゃつく
  2. 紙のマフィンカップに入れたまま1個ずつラップ → ジップ袋へ。結露はラップの内側につくが、紙カップが吸ってくれる
  3. 保存3週間（フルーツ入りは水分が多いので短め）

お弁当に（自然解凍）

油脂・糖・水分が多いケーキ寄りの生地なので、常温に戻ると普通にしっとりします。冷蔵庫より常温解凍の方が食感が良い。

朝7時に冷凍庫から出して保冷剤と一緒に → 12時にちょうど食べ頃。着いたら冷蔵庫へ。

夏場は保冷剤を必ず。ギリシャヨーグルト・卵・クリームチーズ入りで水分活性が高い生地です。市販の「自然解凍OK」冷凍食品は専用に殺菌設計されているので、前提が違います。

温め直し

環境やり方
医局（トースターあり）自然解凍で中まで戻してから、トースター2〜3分。これが最適解。表面だけ水分が飛んで、中はしっとりのまま
家（トースターなし）フライパン弱火・蓋をせず片面2分ずつ。蓋をすると蒸れる
オーブン180℃で5分（確実だが1個のために予熱するのは面倒）
レンジのみラップを外して加熱し、そのまま1〜2分置く。蒸気が抜けて水っぽさが収まる

調整と、アレンジ

糖質を下げたい日は。レモンジャムを45gに、デーツを1粒に → 約210kcal・糖質27g。フルーツの量はそのままで大丈夫です。

甘くない版（さけるチーズ）
レモンジャムを30gに減らし、塩を2.5gに増やす。デーツを抜いて、さけるチーズ1本を裂いて混ぜ込む。焼き時間は同じ。

塩トマト甘納豆
生地に混ぜると溶けて重くなる。焼き上がりに2〜3粒トッピングが正解。塩気がレモンを立たせます。

時短の仕込み

米粉70g・スキムミルク20g・BP7g・塩1g を袋にまとめたものを6セット常温保存。前夜にオートミールを浸けるだけで、翌朝はボウル1つで混ぜて焼くだけ（実働5分）。週末に2バッチ焼いて冷凍すれば、平日の朝は解凍するだけです。

鮭とゆで卵の
塩昆布和え

このレシピの前提。5切れがくっついたまま冷凍して、冷凍焼けした鮭を使い切るために組んでいます。もちろん普通の鮭でも成立しますが、パサつきと酸化臭を消す工程が全体の設計思想になっているので、そこだけ省かないでください。

材料（4〜5食分）

■ メイン

生鮭（切り身）
冷凍焼けしていてOK		5切れ / 450g
卵5個
冷凍ブロッコリー
凍ったまま使う		200g
冷凍コーン
凍ったまま使う。抜いてもいい		100g

■ 下ごしらえ用

塩 解凍する水1Lに対して大さじ2
酒大さじ1

■ 味つけ

塩昆布15g
ごま油大さじ1.5
酢小さじ2
しょうゆ小さじ1
白いりごま大さじ1

作り方

  1. 塩水で解凍する（20分）フライパンに40℃くらいのぬるま湯1L＋塩大さじ2を張り、凍った塊のまま沈める。15分で5切れが自然に剥がれるので、バラしてさらに5分。中心まで解凍しなくていい。真水だとドリップが出てさらにパサつくので、必ず塩水で。
  2. 削いで、拭く白く乾いた冷凍焼け部分と、黒ずんだ血合いを削ぐ。匂いの正体は皮下脂肪の酸化なので、鼻にくるなら皮も外す。酒をふって10分おき、ペーパーで水気を取る。
  3. フライパンを拭いてから焼く湯を捨てたらペーパーでフライパンを完全に拭く。水が残っていると蒸し焼きになって焦げ目がつかない。空のまま中火で温め、ごま油大さじ1を引いて鮭を入れる。
  4. 2〜3分は触らない半解凍のうちからほぐすと水が出て、白っぽいそぼろになります。片面に焼き色がついてからヘラで割り、断面をまた焼きつける。皮は焼けると勝手に剥がれるので、そのタイミングで中骨ごとつまみ出す。
    中心がまだ凍っていたら、酒大さじ1を回しかけて蓋を2分。焼き続けて待つと外側が硬くなります。
  5. 熱いうちに塩昆布を和える鮭を取り出し、熱いうちに塩昆布15gと水（または酒）大さじ1をかけて置いておく。塩昆布が戻るときに出たうま味の汁を、熱い鮭が吸います。やっていることは焼き浸しと同じ。
  6. 同じフライパンで野菜を焼く火を強め、凍ったままのブロッコリーとコーンを投入してしばらく触らない。水が飛んで焦げ目がつきます。鮭のうま味も拾ってくれる。鮭と一緒に炒めないこと（野菜の水で鮭が蒸される）。
  7. 卵は固ゆで9〜10分半熟は作り置きに向きません。冷水にとって剥き、4等分くらいの乱切りに。
  8. 全部合わせるボウルで鮭・野菜・卵を合わせ、酢小さじ2・しょうゆ小さじ1・残りのごま油・白ごまで和える。卵は崩れすぎない程度に。

パサつかせない、たったひとつのコツ。焼き上がりの熱いうちに油をまとわせること。油膜が乾燥を止めるので、冷めてもパサつきません。冷凍焼けした身ほど効きます。

酢は省かないこと。味の輪郭と日持ちの両方を担当しています。入れると4日目まで味がダレません。

失敗しないための原則

水っぽくなる原因は3つ。全部つぶす。

  • 冷凍野菜を茹でる … 茹でずに凍ったまま焼く。水が飛んで香ばしさまで手に入る
  • 鮭と野菜を一緒に炒める … 野菜から出た水で鮭が蒸される。鮭を先に、野菜をあとに
  • フライパンを拭かない … 解凍の湯を捨てただけでは水が残る。焦げ目がつかず、酸化臭が消えない

だしで煮るより、焼いてから吸わせる。低温のだしで煮る手法は理屈としては正しいのですが、この料理には向きません。水分が増えて作り置きが持たないうえ、酸化臭を一番強く覆い隠すのはメイラード反応の香ばしさだからです。焼いてから少量のだしを吸わせる「焼き浸し」なら、両方手に入ります。

油をケチらない。1食あたり33kcal。ここを抜くと別物になります。

塩昆布がないときは。かつお節2パック（5g）＋しょうゆ大さじ1に置き換え。かつお節のほうが作り置きには有利で、余分な水分を吸ってくれるので4日目でも水っぽくなりません。めんつゆなら大さじ1弱＋水大さじ1、顆粒和風だしなら小さじ1/3＋水大さじ2＋塩ひとつまみ。

冷凍と、職場への持っていき方

ゆで卵は冷凍できません。白身の水分が氷の結晶になって離水するので、解凍するとスポンジかゴムのような食感になります（黄身は平気）。冷凍するときは卵だけ抜く。

冷蔵する場合

  • 3日。律速はゆで卵で、鮭と野菜だけなら4日もつ
  • 取り分けは清潔な箸で。保存容器に直箸を入れないのが3日もたせるコツ
  • ゆで卵は殻付きのままなら冷蔵1週間。剥いた瞬間に3日に落ちるので、殻が事実上の保存容器。後半に食べる分は殻付きで取り置き、当日剥いて合流させると余裕が出る

冷凍する場合

  • 卵を抜いた状態で1食ずつラップ → 3週間
  • ほぐした鮭は冷凍に向いています（鮭フレークが元々そういうもの）
  • 前夜に冷蔵庫へ移して自然解凍、朝ゆで卵を足す
  • ブロッコリーは二度目の冷凍で少し柔らかくなるが、和え物なので気にならない

お弁当に

卵抜きの冷凍ブロックを凍ったまま持っていくのが、一番安全で一番ラク。それ自体が保冷剤になり、昼にはちょうど食べ頃に解けています。ゆで卵は別容器で持って、食べる直前に合流。

夏場は保冷剤を必ず。魚・卵・加熱後に手で和えた料理という、一番気をつけたい組み合わせです。詰めるのは当日の朝、完全に冷めてから蓋（温かいまま閉じると結露して水滴が菌の温床になる）。

温め直し

環境やり方
医局（トースターあり）冷たいままでおいしい料理なので、基本は温めなくてよい。温めるならレンジ600Wで1分
家（トースターなし）フライパン弱火・蓋をせず2分。蓋をすると蒸れて水っぽくなる
レンジのみラップを外して1分。卵が入っているので加熱しすぎない

調整と、アレンジ

糖質を下げたい日は。コーンを抜く → 249kcal・糖質1.7g（食物繊維は2.4gに下がる）。糖質のほぼ全部がコーン由来なので、レバーはここ1本で足ります。逆に言えばコーン100gを入れても1食あたり糖質+3.5g・+18kcalなので、入れるデメリットはほぼありません。

4日食べても飽きないための味変（食べる直前に足すだけ）
・柚子胡椒少々＋マヨ小さじ1 … 一番手っ取り早い
・叩き梅＋大葉 … 冷凍焼け臭が一番消える
・焼き海苔をちぎる＋ごま油 … 韓国風ナムル寄りに
・カレー粉小さじ1/4＋粒マスタード … 洋風に振れる

ベースブレッドに挟むなら
味つけを無糖ギリシャヨーグルト100g＋粒マスタード小さじ2＋レモン汁小さじ2＋オリーブオイル大さじ1に置き換える。玉ねぎ1/4個をみじん切りにして塩もみし、しっかり絞ってから加える（絞らないとパンが湿る）。パンは軽くトーストしてから挟むと、具の水分とちょうど釣り合います。
